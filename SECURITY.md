# Security

Report a security or privacy vulnerability privately, through this repository's private vulnerability reporting form:
https://github.com/Bariscanates404/decisionbook/security/advisories/new

What is relevant: unintended access to the local stores (`.decisionbook/`, `.atlasbound/`, `~/.atlasbound/`), unsafe shell
execution, bypasses of documented controls, and unexpected data disclosure.

Please include the version (`atlasbound --version`), your operating system and Node version, the steps that show the
problem, what you expected and what happened.

Please keep the details out of public issues.

Reports are reviewed as maintainer capacity permits. There is no response deadline and no bounty. Fixes go to the latest
release.
